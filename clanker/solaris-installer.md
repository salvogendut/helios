bootloader milestone. Both Solaris 2.6 and 7 now reach `Select a Language`
on TTYA. That milestone stopped before installation choices, with no hard disk
attached and read-only media. It was committed/pushed as

## Hardware and media

Same SS5/85, 128 MiB, original OBP 2.15/TurboGX, Type 5 keyboard and Sun identity
08:00:20:c0:ff:ee / 80c0ffee. Use ignored
`local/probes/graphics-ss5/128m-configured-nvram.bin`, generated by real OBP
commands (`auto-boot?` and `diag-switch?` false). No ROM or NVRAM byte patches.
Only SCSI target 6 is attached. Both complete source ISOs and hashes are in
[firmware.md](../docs/firmware.md#solaris-cd-bootloader-output).

The ignored runner `local/probes/solaris-boot/probe.rs` sends keyboard events for
`ttya io` at step 60M and bytes `boot cdrom -v\r` into the real TTYA FIFO at 70M.
It services ordinary CPU/device execution, drains serial output and Ethernet
frames, and logs ESP IRQ/CDB state. It does not inject firmware output, network
responses or boot data. Local `*-serial.log` files contain raw TTYA bytes;
`*.log` files contain event/step traces. Strip spinner pairs (`.\x08`) for display.

## Fixes and sources

- CD PREVENT ALLOW MEDIUM REMOVAL: SCSI-2 9.2.4. Lock state clears on ALLOW
  or hard bus reset; locked eject returns 05/53/02. Initial unsupported 1e
  CHECK CONDITION responses caused both kernels' `vfs_mountroot` panic.
  Solaris 7 also tests optional PERSISTENT RESERVE IN (5e), tolerates ILLEGAL
  REQUEST and continues. Do not implement reservations merely to hide sense.
- SCC asynchronous CRC reset plus receive/transmit/BREAK interrupts: Zilog
  1992 sections 2.4.4–2.4.9 and chapter 5. RX first/all-character modes, TX
  empty transitions, shared vector/priority, master enable and latched BREAK.
  Sun4m has no SCC acknowledge cycle, hence no IUS set merely on reception.
  Software IACK remains unsupported. Both chips drive level 12 through their
  own controller source/mask. No serial bit timing or error injection.
- DMA2 E_TST_CSR and E_VLD: NCR89C100 pages 3-21–3-22. Track real DMA E_ADDR,
  retain LRU/DIRTY control, report the coherent model's empty cache. Drains
  complete immediately. Tag loading, cache fill and nonzero valid injection
  remain explicit stops. Solaris 2.6 previously stopped reading 78400014 at
  step 957811871, PC f5cf7e5c.
- DMA2 A5 alias: NCR table 2-7 footnote 2 and table 3-1 decode bits 4:0.
  Model the second 32 bytes through the same SCSI/Ethernet register state.
  Solaris 7's read of PA 78400020 formerly panicked (VA f5d1f020,
  PC f5b4dd78, panic text at step 1184851621). QEMU has a different special
  alias to its Ethernet register 1 for this guest access; Helios uses the
  documented shared decode. Wider mirrors beyond 64 bytes remain unmodeled.

## Evidence and limits

Both kernels identify 128 MiB and mount `/.../sd@6,0:b` as UFS root. Releases:
SunOS 5.6 Generic_105181-05 and SunOS 5.7 Generic_106541-08. SCC, CGsix and
Ethernet drivers attach. First language-heading stops:

| Image | Run | Step |
| --- | --- | --- |
| Solaris 2.6 | `sol26-dma` | 1522202105 |
| Solaris 7 | `sol7-alias` | 1686400176 |

The final runner waits another 10M steps after detecting the heading and at
least 1M steps of serial silence to capture the complete menu. Its cap is 6B;
it also stops on guest panic or host error. `sol26-final` and `sol7-final`
are the final-code runs. Do not mistake a transient `Size:` line for OS startup.

Both final runs completed with the entire English/German/Spanish/French/Italian/
Swedish menu and a trailing `?`: `sol26-final` step 1532202106 and `sol7-final`
step 1696400177. No host error, panic or menu input. Original ISO/ROM SHA-256
values still match. These are complete prompt captures, unlike the earlier
heading-only stops.

The functional 100 ns quantum makes the kernels measure 10 MHz and emit an
SBus-frequency warning despite the intended SS5/85 profile. Do not claim
accurate CPU/cache timing, installation, installed-OS operation, graphical
installer compatibility or external networking. Both tested paths still use
2048-byte CD blocks; separate synthetic tests validate 512-byte MODE SELECT.

348 core tests and four UI tests pass; both fmt/Clippy checks, release builds
and all four demos pass. Regressions cover lock/sense/reset, SCC IRQ behavior
and atomic backpressure, DMA diagnostic state and A5-alias bus protections.
